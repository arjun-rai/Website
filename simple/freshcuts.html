Freshcuts

Full-Stack Software Engineer · Oct 2025 — May 2026

This was an idea for a booking app for haircuts where, instead of starting by choosing a barber, the user finds the hairstyle they want and then books with that barber. I worked on the iOS app, backend, and the cloud infrastructure.

description

Barbers upload sample haircuts to the app, which are displayed to users in search and discovery. The user can then find the hairstyle they like the best, try it on using image generation, and then book with that barber. The hairstyle they chose stays connected to the appointment, so the barber or hairstylist has a reference for what the client wants.

I developed the mobile app (Swift + SwiftUI) and the Supabase/Postgres backend, including the data model, authentication, media storage, and real-time booking workflows. I also added ML-powered image processing for virtual try-ons.
